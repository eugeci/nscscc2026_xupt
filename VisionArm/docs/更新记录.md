# 变更时间线

## 阶段 0：官方参考 SoC

- 官方 Loongson/OpenLA500 SoC、DDR MIG、UART、GPIO、MAC 和 VGA 彩条基础。

## 阶段 1：OV5640 + BRAM 稳定成像

- 增加摄像头 DVP/SCCB 引脚。
- SCCB 读取传感器 ID、配置 320x240 RGB565。
- 双时钟 BRAM 完成 `cam_pclk` 到 VGA 时钟域跨域。
- VGA 640x480，源像素 2x2 放大。

## 阶段 2：DDR/VDMA 视频流

- DVP 数据转 AXI-Stream。
- VDMA S2MM 写 DDR 双缓冲、MM2S 读出。
- AXIS 行缓存驱动 VGA。
- 增加帧隔离、状态灯和仿真测试。

## 阶段 3：Linux/CPU 控制

- CONFREG 增加 camera control/status MMIO。
- Linux `cam`/`camctl` 支持 on/off/status。
- UART0 输出被动镜像到 80x30 VGA 文本终端。

## 阶段 4：机械臂

- FPGA 加入独立 9600-8-N-1 UART TX，地址 `0x1fd0e010`。
- ESP32 保留原机械臂底层，只将入口改成 UART2 RX(GPIO17)。
- Linux `arm`/`armctl` 支持 X/Y/Z、夹爪和状态。

## 阶段 5：LCD

- ALIENTEK 4.3-inch NT35510 16-bit 8080 接口与 XDC。
- DDR RGB565 帧读取、异步 FIFO、800x480 显示。
- Linux `lcdctl` 和 Naruto RGB565 图片。
- 增加 LCD control/frame/status MMIO。

## 阶段 6：Linux 镜像

- 重新构建 5.14.0-rc2 内核和 initramfs。
- 从配置层关闭 `CONFIG_MTD_NAND_LS1A`，不再依赖二进制打补丁。
- 固化 arm/cam/lcdctl/snake。

# VisionArm 使用手册

## 1. 启动 Linux

- Tftpd32 目录：`D:\openla500_run_linux\tftp-root`
- Tftpd32 绑定地址：`192.168.1.100`
- 内核文件：`vmlinux_lcd`
- 串口参数：115200、8N1、无流控

PMON 中依次执行：

```sh
ifconfig dmfe0 192.168.1.101
load tftp://192.168.1.100/vmlinux_lcd
g console=ttyS0,115200 rdinit=/sbin/init mem=120M
```

看到 `Please press Enter...` 后按回车，出现 `/ #` 即启动成功。

## 2. 推荐启动顺序

LCD 和摄像头共用一个 DDR AXI 读端口，必须按以下顺序启动：

```sh
lcdctl show
# 等待出现：lcdctl: image displayed
cam on
```

此时：

- 4.3 寸 LCD 保持显示内置图片；
- VGA 显示摄像头实时画面；
- 摄像头继续通过 VDMA 读写 DDR。

摄像头运行后不要再次执行 `lcdctl show`，否则 LCD 可能混入摄像头画面。需要重新显示图片时，复位并重新按照上述顺序操作最稳妥。

## 3. 摄像头

```sh
cam info
cam status
cam on
cam test
cam watch 10
```

正常状态：Sensor ID、SCCB init、DMA、VDMA 为 `yes`，SCCB、VDMA、FIFO 无错误。

不要单独执行 `cam off`。当前视频通路为：

```text
OV5640 320×240 RGB565
  → VDMA 写入 DDR
  → VDMA 从 DDR 读出
  → FPGA 放大为 640×480
  → VGA
```

## 4. ALIENTEK 4.3 寸 LCD

```sh
lcdctl status  # 查看 LCD、DDR 和 AXI 状态
lcdctl show    # 显示内置 800×480 图片
lcdctl bars    # 显示硬件彩条
lcdctl off     # 关闭 LCD 背光
```

`lcdctl show` 将 `/vision/naruto.rgb565` 写入 DDR `0x07800000`，FPGA 经 AXI、异步 FIFO 和 8080 总线送往 NT35510 LCD。

正常的 `lcdctl status` 应满足：

```text
initialized: 1
panel done : 1
AXI error  : 0
```

## 5. 机械臂

```sh
arm hello
arm x forward 200
arm x reverse 200
arm y up 200
arm y down 200
arm z forward 100
arm z reverse 100
arm grip open
arm grip close
```

步数必须是 100 的整数倍，范围 100～5000。调试时先使用 100 或 200 步。夹爪到达机械限位后若持续异响，应立即断开机械臂电机电源。

## 6. 常见问题

- Linux 卡在 PMON：确认 Tftpd32 绑定 `192.168.1.100`，等待 `load` 完成后再执行 `g`。
- LCD 混入摄像头画面：启动顺序错误；复位后先执行 `lcdctl show`，完成后再执行 `cam on`。
- 摄像头异常：执行 `cam status` 和 `cam test`。
- LCD 不显示：执行 `lcdctl status` 和 `lcdctl bars`，检查 `AXI error`。
- 机械臂不动：检查 ESP32 供电、FPGA TX 到 ESP32 GPIO17，以及两块板是否共地。
- 串口乱码：确认 115200、8N1、无流控，并确保只有一个软件占用串口。

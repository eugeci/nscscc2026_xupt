# 摄像头、DDR、VGA、LCD 时钟

摄像头和 LCD 没有各自增加一颗 FPGA PLL。工程复用官方 SoC 的 Clock Wizard/MIG，并用
异步 FIFO 跨时钟域。

| 域 | 来源 | 频率和用途 |
|---|---|---|
| `clk` | 板载晶振 | 100 MHz；SCCB、复位计时、LCD 8080 |
| `cpu_clk` | `clk_pll_33.clk_out1` | 40.000 MHz；CPU（合并设计的时序收敛频率） |
| `uncore_clk` | `clk_pll_33.clk_out2` | 约 33.143 MHz；SoC uncore、NPU、CONFREG |
| `vga_clk` | `clk_pll_33.clk_out3` | 约 50.435 MHz；VGA、UART VGA 终端、VDMA 视频流 |
| `c1_clk_ref_i` | `clk_wiz_0` | 200 MHz；MIG reference |
| `c1_clk0` | MIG `ui_clk` | 100 MHz；DDR AXI/VDMA/LCD DDR reader |
| `cam_pclk` | OV5640 模组输出 | 外部摄像头像素时钟；不是 FPGA PLL 输出 |
| VGA pixel enable | `vga_clk` 内部二分频 | 约 25.217 MHz，640x480@约 60 Hz |
| LCD 8080 | 100 MHz 状态机 | low 2 + high 2 cycles，约 25 Mword/s |

MIG 配置为 DDR3 400 MHz（2.5 ns）、4:1 PHY，因此 UI 时钟为 100 MHz。

跨域点：

- `cam_pclk -> c1_clk0`：摄像头采集异步 FIFO；
- `c1_clk0 -> vga_clk`：VDMA MM2S 视频 AXIS；
- `c1_clk0 -> clk(100MHz)`：`lcd_async_fifo32`。

CPU 与 VGA 必须使用独立输出。若把 VGA 模块接回 40 MHz `cpu_clk`，模块内部二分频
只会得到 20 MHz 像素节拍，640x480 帧率降至约 47.6 Hz，部分显示器会直接报告无信号。

XDC 中 `cam_pclk` 的 10 ns 是 STA 上限约束，不等于摄像头 PCLK 实测就是 100 MHz。
